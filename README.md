# Vidya Piske · Portfolio

Personal portfolio of Vidya Piske, Frontend Engineer.

**Live:** https://vidya-piske.github.io

## Stack

- **Next.js** (App Router) with static export (`output: "export"`)
- **React** + **TypeScript**
- **Tailwind CSS v4**
- Hosted on **GitHub Pages**, deployed by GitHub Actions on every push to `master`

## Run locally

```bash
npm install
npm run dev
```

## Where things live

- `src/lib/data.ts` — all site content (experience, projects, skills, contact)
- `src/components/sections.tsx` — page sections
- `src/components/` — interactive pieces (nav + dark mode, draggable sticker board, scroll reveal, copy email)
- `src/app/globals.css` — colours, theme tokens, animations
- `public/` — resume PDF and project screenshots
